# Wing Optimization Profile

#Brief Overview
This project was developed in order to inform a design for 3D printed wings, it takes current design constraints from a Bambu Labs P1S printer and parametrically tests NACA profiles based on the equation for NACA 4 digit generator
from airfoil tools.
After the NACA profile is developed it is tested based on chord for printability and then its aerodynamic performance is rated with xfoil tools. A list of profiles is then published at the end based on performance. 
The intention is to fork the best performing profiles in to a parametric CAD design and run it through CFD.
